# V3mod-ItalyJournal

《维多利亚3》意大利专属日志模组，当前内容为第一阶段：意大利统一（`phase1-unification`）。模组元数据名称为 `myItalyJournal`。

## 设计目标

以萨丁—皮埃蒙特为主角，通过工业化、宪政改革、民族统一和统一后的政教冲突，为意大利提供一条有经济基础、政治选择和后续矛盾的国家发展路线。

整体叙事方向为：建设皮埃蒙特 → 推进政治改革 → 统一意大利 → 解决罗马问题。当前实现中，工业化与宪政改革是可并行推进的日志，并非统一的硬性前置条件。

## 当前内容

### 萨丁—皮埃蒙特工业化

- 萨丁拥有皮埃蒙特并研究水管锅炉后，可开启工业化日志。
- 进行期间为皮埃蒙特提供建设、移民吸引力等加成。
- 皮埃蒙特城镇中心达到 5 级后完成，获得长期工业加成，并通过事件授予菲亚特公司。
- 失去皮埃蒙特会导致日志失败。
- 同时调整 ILVA 公司，使其以皮埃蒙特的煤、铁、钢铁产业为基础，扩展至铁路，并通过繁荣奖励支持建设。

### 阿尔贝特宪法

- 面向拥有皮埃蒙特、且不是附属国的萨丁。
- 日志进行期间缩短立法时间，以通过资格性选举为完成目标。
- 完成事件授予知识分子政治力量加成。
- 失去皮埃蒙特会导致日志失败。

### 意大利统一

- 面向研究民族主义、且不是附属国的萨丁。
- 开始时提高意大利文化热情、设置统一倾向变量，并向符合条件的其他意大利文化国家传播民族主义科技。
- 触发红衫军出征事件，提高两西西里意大利文化人口中的激进派比例；事件选项增加本国相应文化人口中的效忠派。
- **整合北意诸邦**：成为统一候选人后，一次性吞并满足脚本条件的北意国家，包括非玩家、非列强、关系至少中立，并排除指定国家及部分附属国类型。
- **吞并两西西里**：成为唯一的意大利统一候选人后，可一次性直接吞并仍存在的两西西里。
- 国家成为意大利时完成日志；设计上通过统一完成事件授予奖励，并接入罗马问题。

### 罗马问题

统一后的核心矛盾是新国家与教廷之间的权力关系。

- 开场事件尝试创建教皇国，并设置其领土、神权制度及执政利益集团。
- 玩家选择打压教会的世俗权力，或与教会妥协，获得相应的教会政治力量修正。
- 在 1825 天（约五年）内通过完全分离法律，可吞并教皇国、迁都拉齐奥，并调整虔诚者利益集团的意识形态。
- 超时则强制恢复国教制度，并增加教会政治力量。
